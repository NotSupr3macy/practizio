# practizio

An MCP-connected directory designed to make small professional practices (medical, dental, legal) discoverable and bookable by AI agents — not just by humans browsing the web.

## The thesis
As more consumers shift from app-based search to AI agents for finding and booking services, the businesses that expose structured, agent-readable availability and booking endpoints will win disproportionate share. Practizio is a registry layer for those endpoints, accessible via MCP so any compliant AI client can query and transact against it.

## Stack
Node.js · Supabase · MCP server · structured business metadata schema (services, hours, booking endpoints, location)

## Status
Initial implementation parked while focus shifted to Spadechat's AI receptionist product. The directory concept remains a candidate expansion once the receptionist client base creates a natural supply side of bookable practices.
